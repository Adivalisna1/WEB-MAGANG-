## Stack Teknologi Web Ini

| Bagian | Teknologi |
|---|---|
| **Frontend** | Next.js 14 (React + TypeScript) |
| **Backend** | Node.js + Express.js |
| **Database** | MySQL 8.0 |
| **Styling** | Tailwind CSS |
| **Auth** | JWT (JSON Web Token) + bcrypt |
| **Infrastructure** | Docker + Docker Compose |

---

## Alur Navigasi Web (4 Lapis)

```
[1] Landing Page (localhost:3000)       ← Publik, tanpa login
         ↓ klik "Masuk ke Dashboard"
[2] Halaman Login (localhost:3000/login) ← Form login
         ↓ berhasil login
[3] Dashboard Laporan (/laporan)         ← Harus login — lihat & unduh dokumen
         ↓ sesuai role
[4] Dashboard User                       ← /admin | /ketua | /staff/dokumen
```

## Step by Step Cara Nyalain di Localhost

### Syarat awal
- Docker Desktop sudah terinstall dan running
- Project ada di folder `c:\Users\adiva\OneDrive\Dokumen\web magang munculin data`

---

### Step 1 — Buka Docker Desktop
Buka dari Start Menu, tunggu sampai icon di taskbar stabil (tidak loading)

---

### Step 2 — Buka PowerShell, masuk ke folder project
```powershell
cd "c:\Users\adiva\OneDrive\Dokumen\web magang munculin data"
```

---

### Step 3 — Jalankan semua container
```powershell
docker-compose up -d
```

Tunggu sampai muncul output seperti ini:
```
✔ Container web_laporan_db        Started
✔ Container web_laporan_backend   Started
✔ Container web_laporan_frontend  Started
✔ Container web_laporan_pma       Started
```

---

### Step 4 — Cek semua container running
```powershell
docker-compose ps
```

Harusnya 4 container running:
```
web_laporan_db        → running (healthy)
web_laporan_backend   → running
web_laporan_frontend  → running
web_laporan_pma       → running
```

### Cara matikan web
```powershell

```

---

### Rebuild setelah ada perubahan kode

```powershell
# Rebuild semua (paling aman)
docker-compose up -d --build

# Rebuild frontend saja (lebih cepat)
docker-compose up -d --build frontend

# Rebuild backend saja
docker-compose up -d --build backend
```

> **Catatan:** Setiap ubah file `.env` (terutama `NEXT_PUBLIC_API_URL`), wajib rebuild frontend.

---

### Troubleshooting

**Container tidak mau jalan:**
```powershell
docker-compose logs backend
docker-compose logs frontend
```

**Foto gedung tidak muncul di landing page:**
- Pastikan file `frontend/public/gedung-dikti.avif` ada
- Jalankan rebuild: `docker-compose up -d --build frontend`

**Login gagal / "Failed to fetch":**
- Pastikan backend running: `docker-compose ps`
- Pastikan `NEXT_PUBLIC_API_URL=http://localhost:5000/api` di file `.env`

**Port sudah dipakai:**
```powershell
# Ganti port di file .env
MYSQL_PORT=3308
APP_PORT=5001
```

**Rebuild dari awal:**
```powershell
docker-compose down
docker-compose up -d --build
```
